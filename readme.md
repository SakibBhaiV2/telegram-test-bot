# Recharge To Cash - মোবাইল রিচার্জ টু ক্যাশ কনভার্টার সিস্টেম

একটি সম্পূর্ণ, প্রোডাকশন-রেডি, কর্পোরেট-গ্রেড এবং মোবাইল-ফার্স্ট ওয়েব অ্যাপ্লিকেশন। এর মাধ্যমে ব্যবহারকারীরা তাদের মোবাইল সিমের অব্যবহৃত রিচার্জকৃত ব্যালেন্স পাঠিয়ে সমপরিমাণ অর্থ (নির্ধারিত কমিশন কর্তন সাপেক্ষে) ক্যাশ ব্যালেন্সে রূপান্তর করতে পারেন এবং বিকাশ, নগদ, রকেট বা উপায় ওয়ালেটে ক্যাশ আউট / উইথড্র করে নিতে পারেন।

প্রজেক্টটি খাঁটি পিএইচপি (Pure PHP 8.2) এবং পিডিও (PDO) ব্যবহার করে নির্মিত, যা লোকাল XAMPP এবং ফ্রি হোস্টিং যেমন InfinityFree-তে সম্পূর্ণ ঝামেলাহীনভাবে চলতে সক্ষম।

## ১. প্রজেক্ট পরিচিতি ও প্রধান বৈশিষ্ট্যসমূহ

- ইউজার ইন্টারফেস সম্পূর্ণ বাংলায় তৈরি এবং মোবাইল-ফার্স্ট রেসপন্সিভ ডিজাইন।
- সর্বদা লাইট থিম: ক্লিন কর্পোরেট লুক, নীল ও সাদা রঙের সংমিশ্রণ, সফট শ্যাডো ও গোলাকার কার্ড।
- কোনো ইমোজি ব্যবহার করা হয়নি; প্রফেশনাল কর্পোরেট এসভিজি (SVG) আইকন ব্যবহৃত।
- কোনো ডামি ডেটা নেই; ডেটাবেস সম্পূর্ণ বাস্তবসম্মত ও পরিষ্কার।
- ৩-ধাপ বিশিষ্ট সহজ টাকা রূপান্তর ফ্লো (অপারেটর ও পরিমাণ নির্বাচন -> রিসিভিং নম্বরে টাকা পাঠানো -> ইউজার নিশ্চিতকরণ)।
- মোবাইল স্ক্রিনের নিচে ফিক্সড বটম নেভিগেশন বার এবং ডেস্কটপে মার্জিত টপ নেভিগেশন বার।
- শক্তিশালী ইউজার অ্যাকাউন্ট সিস্টেম (ইমেইল ভেরিফিকেশন, পাসওয়ার্ড রিসেট, প্রোফাইল ম্যানেজমেন্ট)।
- সম্পূর্ণ সুরক্ষিত অ্যাডমিন কন্ট্রোল প্যানেল (কোনো ইউজারনেম নেই, শুধু মাস্টার পাসওয়ার্ড প্রোটেকশন)।
- অ্যাডমিন প্যানেল থেকে গতিশীলভাবে সাইটের নাম, লোগো, কমিশন হার, মিনিমাম উইথড্র লিমিট, সিম নম্বর এবং জিমেইল এসএমটিপি সেটিংস পরিবর্তনের সুবিধা।

## ৩. XAMPP লোকাল সার্ভারে সেটআপ পদ্ধতি

ধাপ ১: ফোল্ডার স্থানান্তর
- XAMPP ইনস্টল করা ডিরেক্টরিতে যান (সাধারণত `C:\xampp\htdocs\`)।
- এই প্রজেক্টের সমস্ত ফাইল একটি ফোল্ডারে রাখুন (যেমন: `C:\xampp\htdocs\recharge-to-cash\`)।

ধাপ ২: ডেটাবেস তৈরি ও ইমপোর্ট
- XAMPP কন্ট্রোল প্যানেল থেকে Apache এবং MySQL চালু করুন।
- ব্রাউজারে যান: `http://localhost/phpmyadmin/`
- "New" বাটনে ক্লিক করে `recharge_to_cash` নামে একটি নতুন ডেটাবেস তৈরি করুন (Collation: `utf8mb4_unicode_ci`)।
- ডেটাবেসটি নির্বাচন করে "Import" ট্যাবে যান।
- প্রজেক্ট ফোল্ডারে থাকা `database.sql` ফাইলটি নির্বাচন করুন এবং নিচে "Go" বা "Import" বাটনে ক্লিক করুন।

ধাপ ৩: ডেটাবেস কনফিগারেশন আপডেট
- আপনার কোড এডিটরে `config/database.php` ফাইলটি খুলুন।
- লোকাল XAMPP-এর তথ্য যাচাই করুন:
  - `$db_host = 'localhost';`
  - `$db_name = 'recharge_to_cash';`
  - `$db_user = 'root';`
  - `$db_pass = '';`
- তথ্য সংরক্ষণ (Save) করুন।

ধাপ ৪: PHPMailer যাচাই
- প্রজেক্টের সাথে `vendor/` ফোল্ডারে PHPMailer লাইব্রেরি আগে থেকেই অন্তর্ভুক্ত রয়েছে।
- যদি নতুন করে ডিপেন্ডেন্সি আপডেট করতে চান, প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে চালান:
  `composer install`

ধাপ ৫: ওয়েবসাইট ও অ্যাডমিন প্যানেল পরিদর্শন
- সাধারণ ইউজার সাইট: `http://localhost/recharge-to-cash/`
- অ্যাডমিন প্যানেল: `http://localhost/recharge-to-cash/admin/`
- ডিফল্ট অ্যাডমিন পাসওয়ার্ড: `Sakib@7890`

## ৪. InfinityFree-তে ফ্রি হোস্টিং সেটআপ নির্দেশিকা

ধাপ ১: InfinityFree অ্যাকাউন্ট তৈরি ও ডোমেন সেটআপ
- InfinityFree-তে একটি নতুন ফ্রি অ্যাকাউন্ট খুলুন এবং একটি সাবডোমেন বা নিজস্ব ডোমেন যুক্ত করুন।
- কন্ট্রোল প্যানেল (vPanel) থেকে আপনার অ্যাকাউন্টের বিবরণ দেখুন।

ধাপ ২: ফাইল আপলোড
- InfinityFree-এর File Manager অথবা FileZilla (FTP Client) ব্যবহার করে আপনার অ্যাকাউন্টের `htdocs` ফোল্ডারে প্রবেশ করুন।
- লোকাল কম্পিউটার থেকে প্রজেক্টের সমস্ত ফাইল ও ফোল্ডার (`config/`, `includes/`, `admin/`, `assets/`, `vendor/`, `index.php` ইত্যাদি) `htdocs` ফোল্ডারে আপলোড করুন।
- মনে রাখবেন: InfinityFree-তে SSH বা Composer কমান্ড চালানোর সুবিধা নেই, তাই লোকাল কম্পিউটারের সম্পূর্ণ `vendor/` ফোল্ডারটি অবশ্যই হুবহু আপলোড করতে হবে।

ধাপ ৩: MySQL ডেটাবেস তৈরি
- InfinityFree vPanel-এ গিয়ে "MySQL Databases"-এ ক্লিক করুন।
- নতুন একটি ডেটাবেস তৈরি করুন। তৈরির পর আপনি Database Host (যেমন: `sqlXXX.infinityfree.com`), Database Name, Username এবং Password দেখতে পাবেন।
- vPanel থেকে "phpMyAdmin"-এ প্রবেশ করুন।
- আপনার সদ্য তৈরি ডেটাবেসে ক্লিক করে `database.sql` ফাইলটি "Import" করুন।

ধাপ ৪: config/database.php আপডেট
- InfinityFree File Manager-এ গিয়ে `config/database.php` এডিট করুন।
- লোকাল তথ্যের বদলে InfinityFree-এর ডেটাবেস হোস্ট, নাম, ইউজার ও পাসওয়ার্ড বসিয়ে সেভ করুন:
  - `$db_host = 'sqlXXX.epizy.com';` (আপনার vPanel এ যা দেওয়া আছে)
  - `$db_name = 'epiz_xxxx_recharge';`
  - `$db_user = 'epiz_xxxx';`
  - `$db_pass = 'আপনার পাসওয়ার্ড';`

ধাপ ৫: InfinityFree সম্পর্কিত সতর্কতা
- InfinityFree সার্ভার থেকে বহির্গামী থার্ড-পার্টি কাস্টম পোর্ট ও API রিকোয়েস্ট ব্লক থাকে। তবে স্ট্যান্ডার্ড Gmail SMTP (Port 587) সাধারণত সমর্থিত। এই প্রজেক্টে কোনো জটিল থার্ড-পার্টি API ব্যবহার করা হয়নি, তাই InfinityFree-তে এটি স্বাচ্ছন্দ্যে চলবে।

## ৬. নিরাপত্তা পরামর্শ (Security Recommendations)

১. ডিফল্ট পাসওয়ার্ড পরিবর্তন: সাইট অনলাইনে লাইভ করার পর সর্বপ্রথম অ্যাডমিন পাসওয়ার্ড পরিবর্তন করুন।
২. HTTPS প্রটোকল: সর্বদা SSL সার্টিফিকেট (HTTPS) সক্রিয় রাখুন যাতে ব্যবহারকারীর সংবেদনশীল ডেটা ও পাসওয়ার্ড নেটওয়ার্কে এনক্রিপ্টেড থাকে।
৩. ডেটাবেস ক্রেডেনশিয়াল গোপনীয়তা: `config/database.php` ফাইলে সংরক্ষিত ডেটাবেস পাসওয়ার্ড কখনোই উন্মুক্ত পাবলিক রিপোজিটরিতে আপলোড করবেন না।
৪. সেশন ও CSRF সুরক্ষা: সাইটের প্রতিটি ফর্মে CSRF টোকেন ভ্যালিডেশন এবং লগইনে সেশন রিজেনারেশন সক্রিয় রয়েছে যা অননুমোদিত অ্যাকশন প্রতিরোধ করে।
৫. নিয়মিত ডেটাবেস ব্যাকআপ: প্রতি সপ্তাহে phpMyAdmin থেকে `Export` অপশন ব্যবহার করে ডেটাবেসের ব্যাকআপ ফাইল সংরক্ষণ করুন।

## ৮. ট্রাবলশুটিং (সমস্যা ও সমাধান)

১. ডেটাবেস সংযোগ স্থাপন করা সম্ভব হয়নি (Database Connection Error):
   - সমাধান: `config/database.php` ফাইলে দেওয়া Host, Name, User এবং Password সঠিক কি না পুনরায় মিলিয়ে নিন। XAMPP-এ কাজ করলে নিশ্চিত করুন MySQL সার্ভিস চালু আছে।

২. ইমেইল পাঠানো হচ্ছে না (Gmail SMTP Error):
   - সমাধান:
     - সাধারণ জিমেইল পাসওয়ার্ড ব্যবহার করবেন না। গুগলের ১৬ অক্ষরের App Password তৈরি করে ব্যবহার করুন।
     - আপনার জিমেইল অ্যাকাউন্টে ২-স্টেপ ভেরিফিকেশন চালু থাকতে হবে।
     - পোর্ট 587 এর জন্য TLS এনক্রিপশন ব্যবহৃত হয়। আপনার সার্ভার যদি 587 ব্লক করে, তবে পোর্ট 465 দিয়ে চেষ্টা করুন।
     - অ্যাডমিন প্যানেলের "ইমেইল সেটিংস"-এ গিয়ে "টেস্ট ইমেইল পাঠান" দিয়ে বিস্তারিত এরর মেসেজ দেখে নিতে পারেন।

৩. "কোনো সক্রিয় নম্বর নেই" মেসেজ আসছে কেন?
   - সমাধান: ইউজাররা যখন রিচার্জ রূপান্তর করতে যান, সংশ্লিষ্ট অপারেটরের একটি সচল রিসিভিং নম্বর ডেটাবেসে থাকা আবশ্যক। অ্যাডমিন প্যানেলে ঢুকে "সিম নম্বর ম্যানেজমেন্ট" থেকে গ্রামীণফোন, রবি, বাংলালিংক ইত্যাদির নম্বর যুক্ত করে "সক্রিয়" করে দিন।

৪. সিএসএস বা জাভাস্ক্রিপ্ট আপডেট হচ্ছে না:
   - সমাধান: ব্রাউজারের ক্যাশ মেমরি পরিষ্কার করতে কিবোর্ডে `Ctrl + F5` (অথবা ম্যাকে `Cmd + Shift + R`) চাপুন।
